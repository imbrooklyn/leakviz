# leakviz v0.1.1

`leakviz` v0.1.1 is a documentation-only patch release. It fixes the README
link used by the hosted GitHub Release page. Runtime behavior and
machine-readable contracts are unchanged from v0.1.0.

## Install

Install from the v0.1.1 module tag with Go 1.27.x:

```bash
go install github.com/imbrooklyn/leakviz/cmd/leakviz@v0.1.1
leakviz --version
```

A source-checkout build reports `leakviz devel`. A module build from `@v0.1.1`
reports `leakviz v0.1.1` through Go build information.

## Fixed

- Use an absolute, tag-pinned README URL that works from the hosted GitHub
  Release page as well as the repository file view.

## Compatibility

- CLI behavior and exit codes are unchanged.
- JSON schema v1 and fingerprint version 1 are unchanged.
- The Go 1.27 requirement, supported profile inputs, and dependency versions
  are unchanged.
- The release contains no project-built binary or checksum assets.

See the [README](https://github.com/imbrooklyn/leakviz/blob/v0.1.1/README.md)
for complete input rules, options, examples, and v0.1 non-goals.
